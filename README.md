# Week 2 - Sales Data Analysis Using Python

As part of my Week 2 internship, I worked on a sales dataset with 200 records. I used Python and Pandas to explore the data and understand the sales of different product categories.

During this task, I checked for missing values and duplicate records, sorted the data, calculated the total revenue for each category, and explored the relationship between quantity, unit price, and total price.

**What I found:**
- Furniture had the highest revenue.
- Clothing had the lowest revenue.
- The dataset had no missing values or duplicate rows.

**Tools used:** Python, Pandas, and VS Code.

This task gave me hands-on practice with data analysis and helped me become more comfortable working with real datasets.
